# FinSight Financial Analytics Project
> **Course:** Data Analytics Training Program
> > **Institution:** The Incubator Hub
> **Tool Used:** Power BI (Power Query, Data Modeling, DAX)

## 📌 Project Overview
This project is an end to end financial analytics solution developed for the Incubator Hub data analytics course. It transforms raw transactional ledger data and chart of accounts mapping into a star schema model to deliver executive Profit & Loss insights and financial performance metrics.
